# Known limitations

This is a local personal learning application, not remote proctoring or a placement guarantee.

- The immutable scope has 157 topics. Nine have validated candidate lesson/pool pairs; 148 have no authored teaching or assessment pool. All nine still need independent factual, pedagogical, provenance and transfer-independence review. Zero new Placement Foundations lessons or pools are human-approved or published. The complete per-topic gaps are in FINAL_CONTENT_COVERAGE.md and data/placement-foundations-coverage.json.
- The shipping inventory describes this execution's unpublished candidate batch; it is not a live export of future learner publication databases. Regenerate/reconcile it when a human publishes content.
- Initial objective candidate depth is two practice, one transfer, one recall and one interview item for seven topics. That is a small review batch, not a repeated exam bank. AI fundamentals and communication candidates use unscored reflection, without manufactured transfer/recall scores.
- The 53 legacy lessons and historical Arena bank retain original editorial/provenance limitations. No title-based equivalence to the new scope is inferred. Adapted Exercism provenance and corrected Two Sum approval blockers remain unresolved.
- Numeric grading accepts explicit Decimal strings, declared units and tolerance. It is not a general algebra/semantic-expression solver. Alternative valid solutions must be represented in deterministic contracts or reviewed before publication.
- Python submission supports a restricted standard-library subset. SQL submission requires local Node/PGlite. Missing or unsupported workers fail without verified credit. Browser Run uses public samples; it is not the scored verifier.
- Offline use requires dependencies and the production assets to be installed beforehand. Network-denial verification is scoped to browser requests and the Python verification process; no machine-wide firewall or OS-level Node network sandbox is claimed.
- Plan completion records advisory study time, never mastery. Plans may leave substantial time unallocated. Existing saved plan references can become unavailable after a release is revoked; regenerate/replace using currently approved activities. Previous revisions remain in storage; there is no dedicated plan-history browser.
- Local clocks and local administrators are trusted. Test deadlines survive refresh/restart but do not establish tamper-proof remote timing. Scoring is fixed binary contract correctness, not adaptive partial credit or employer prediction.
- Communication rehearsal has no automated correctness score. Candidates and reflections cannot establish hiring readiness, and reading cannot establish coding mastery.
- Bundle size warnings remain for the locally bundled editor/database runtimes. Windows launcher identity safeguards are Windows-specific; equivalent cross-platform desktop packaging is outside this release.

Human content approval and publication remain explicit separate operations; synthetic approvals in disposable tests are never real publication.
